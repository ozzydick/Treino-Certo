### Correções realizadas durante a auditoria

1. O teste da evolução muscular esperava `Séries por semana`, mas a interface utiliza `séries por semana`. Corrigido o texto esperado no teste; não foi necessária alteração na interface.
2. O teste CP09.5 não resolvia os módulos internos `types` e `evolutionCalculator` ao executar a função isoladamente. O harness foi ajustado para carregar os módulos TypeScript reais.
3. A fixture do teste CP09.5 usava valores de `totalVolumeKg` que não correspondiam ao volume derivado das séries reais. A fixture foi alinhada à regra de cálculo por carga x repetições.

### Pendências obrigatórias para homologação final

Não foi possível concluir estas etapas neste ambiente:

- **Build de produção:** `node_modules` não está presente; Vite não está instalado.
- **Lint completo:** `tsc --noEmit` foi tentado, mas falhou porque faltam os tipos `vite/client` e `vite-plugin-pwa/client`, dependências que seriam instaladas junto ao projeto.
- **Navegador:** ainda não foi executado o fluxo real da aplicação compilada.
- **PWA instalada:** instalação, abertura standalone e atualização do service worker ainda precisam ser verificadas.
- **Offline real:** desligar a rede após uma primeira carga, reabrir e percorrer telas/imagens não foi executado.
- **Persistência real:** alternar os sete temas, fechar/reabrir e verificar a preferência no IndexedDB precisa de teste no navegador.

A ausência dessas verificações **não indica defeito confirmado**; significa que a homologação não pode ser declarada concluída sem executar o projeto compilado.

### Como concluir no Windows

Na pasta `treino-certo`, com Bun instalado:

```powershell
bun install --frozen-lockfile
bun run lint
bun run build
```

Depois, executar os testes listados no `package.json`, incluindo:

```powershell
bun run test:cp9.5
bun run test:cp9.5-theme-pwa
```

Para a homologação manual, executar o preview de produção:

```powershell
bun run preview -- --host 127.0.0.1
```

Abrir `http://localhost:4173` no Chrome e verificar:
- aplicação e navegação em desktop e celular;
- alternância e persistência dos sete temas;
- tema OCEANO em todas as telas principais;
- instalação PWA e abertura standalone;
- primeira carga online, depois modo offline e reabertura;
- histórico, execução de treino, imagens, relatórios e backup.
