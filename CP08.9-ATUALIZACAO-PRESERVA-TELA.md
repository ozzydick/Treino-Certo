# CP08.9 — Atualização preservando a tela

- Adicionado botão **Atualizar** no cabeçalho do aplicativo.
- Antes da recarga, registra em `sessionStorage` a aba atual, a visão interna (incluindo Minha Academia), o estado do modal de temas e a posição vertical de rolagem.
- Após a inicialização, restaura a tela e a rolagem e consome o estado temporário para não interferir em aberturas futuras.
- A persistência dos dados de treino continua a cargo dos serviços/IndexedDB já existentes; este recurso não cria uma segunda camada de dados.
- Funciona também quando o usuário aciona o botão com o aplicativo instalado como PWA, desde que o armazenamento da sessão esteja disponível.

## Validação

`npm run test:refresh` verifica os pontos estruturais do fluxo. Ainda é necessária validação manual no navegador e no PWA instalado, incluindo durante uma sessão de treino ativa.
