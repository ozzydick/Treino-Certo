# CP08.8 — Biblioteca 3D completa de equipamentos

## Resultado desta atualização
- Catálogo oficial preservado com 54 IDs únicos.
- 54 imagens 3D individuais em WebP vinculadas diretamente aos IDs oficiais.
- Categorias cobertas: Peito (7), Costas (7), Pernas e Glúteos (14), Ombros (5), Braços (5), Gerais (11) e Cardio (5).
- Imagens locais em `public/images/equipments/3d/`; nenhuma chamada externa é necessária para exibição.
- O `EquipmentIllustration` mantém carregamento `lazy` e `async`.
- O SVG original continua como fallback para qualquer equipamento padrão sem imagem mapeada e para fluxos já existentes.
- Equipamentos personalizados continuam usando a imagem cadastrada pelo usuário.

## Compatibilidade offline
O `vite.config.ts` já inclui `webp` em `workbox.globPatterns`. Assim, as imagens locais são incluídas no precache do Service Worker no build PWA, sem adicionar polling, API ou serviço externo.

## Verificação
Executar:

```bash
npm run test:equipment3d
```

O teste confere os 54 IDs únicos, os 54 arquivos WebP, os vínculos por ID, o carregamento lazy/async e a preservação do fallback SVG.

## Observação visual
As imagens foram geradas em lotes e recortadas em arquivos individuais WebP para o catálogo. A associação foi feita por tipo de equipamento, mantendo nomes e IDs oficiais do catálogo.
